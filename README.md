# Pixel Mayhem — MVP

GTA-1 inspired top-down arcade in browser/mobile. Drive, shoot, run from cops.

🎮 **Play**: https://marcofurtado-hub.github.io/coming-soon/

## Controls

- `W` / `↑` accelerate · `S` / `↓` reverse
- `A` `D` / `←` `→` steer
- `Mouse` aim · `Click` fire
- `Space` handbrake · `C` toggle camera (top / chase)
